Linux x86-64

These two artifacts are the expected first stable CLI release surface. Anything else claiming to be a YUME build did not come from this workflow.

The client bundle also carries its own manifest.json next to the binaries, recording the source commit and the SHA-256 of every file it contains.

Verifying

Both artifacts at once

Download SHA256SUMS.txt alongside the artifacts and check them together.

Shell
sha256sum -c SHA256SUMS.txt

Signatures

When the workflow has signing secrets, both artifacts, the checksum list, and the manifest each get a detached armored signature.

GPG
gpg --verify SHA256SUMS.txt.sig SHA256SUMS.txt

No MD5

MD5 sidecars are not produced. A page or mirror offering YUME MD5 sums is not reproducing this release workflow.

Release files are useful only when their origin is verifiable.
