Verifying

Check the signature on the checksum list first, then check the files against it. The operations guide describes what the release workflow signs and checks before it uploads.

  1. Import the release key

    Get yume-release-key.asc from the repository and confirm its primary fingerprint is 967278FF6FA436F504CBB0058A1588B5E2598DB1 through a source you trust.

    gpg --import yume-release-key.asc
gpg --fingerprint 967278FF6FA436F504CBB0058A1588B5E2598DB1

  2. Check the signatures

    Every artifact, the checksum list and the manifest has a detached .sig file.

    gpg --verify SHA256SUMS.txt.sig SHA256SUMS.txt
gpg --verify release-manifest.json.sig release-manifest.json

  3. Check the files

    Run this in the folder that holds the downloads. Each artifact also has its own .sha256 file.

    sha256sum -c SHA256SUMS.txt
